## Overview

VehicleSnap makes Factorio vehicles automatically align to compass-direction angles when driving, preventing the vehicle drift that makes building straight rail lines and road networks from a car difficult. Configurable snap angles allow 45°, 90°, or free movement depending on task.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio VehicleSnap** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Angle Snapping** | Vehicles snap to compass directions for straight-line driving |
| **Configurable Angles** | Choose between 45°, 90°, or other snap angles per vehicle type |
| **Rail Building Aid** | Keeps cars aligned with rail grid during track planning trips |
| **Toggle Hotkey** | Bind a key to toggle snapping on/off for precision maneuvering |
